# Motion Alarm Using PIR Sensor

This is a small electronics project using a PIR motion sensor. The sensor detects movement and turns on an LED. I made this project to learn the basic working of a PIR sensor and breadboard connections.

---

## About

The project uses a PIR sensor, an LED, a resistor, a breadboard and a 9V battery. When someone moves in front of the sensor, the LED glows for a short time. When there is no movement, the LED remains off.

---

## Components Used

- PIR Motion Sensor
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires
- 9V Battery
- Battery Clip

---

## Features

- Detects human movement
- LED turns ON when motion is detected
- Simple breadboard circuit
- Battery powered
- Easy beginner project

---

## How It Works

1. Connect the battery to the circuit.
2. Wait a few seconds for the PIR sensor to become ready.
3. Move your hand in front of the sensor.
4. The PIR sensor detects the movement.
5. The LED turns ON for a short time.
6. After no movement is detected, the LED turns OFF.
